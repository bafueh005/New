## How to test cleanly

1. Start with **3–4 variants** (e.g. B, C, E, F) so each gets enough budget to reach significance.
2. **Hold the image constant** (`ad-square.png`) and vary only the text first — learn which *message* wins, then test images.
3. Let each run **4–5 days / ~50+ link clicks** before judging.
4. Or use Meta **Advantage+ creative / Dynamic Creative**: drop in multiple primary texts + headlines and let it optimize the combination.
